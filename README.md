# ALIYO-MOMOT-UNIVERSITY-APP

A modern web application for ALIYO MOMOT University - A leading institution specializing in Medical and Engineering education.

## Features

- **Home Page**: University overview with statistics and highlights
- **Departments**: Detailed information about Medical and Engineering departments
- **Courses**: Comprehensive course catalog for both disciplines
- **Student Portal**: Login/Registration interface for students

## Technology Stack

- React 19.2.3
- React Router DOM 7.11.0
- Vite 7.3.0
- JavaScript (ES6+)

## Getting Started

### Prerequisites

- Node.js (v20 or higher)
- npm (v10 or higher)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/aliyomomot-alt/ALIYO-MOMOT-UNIVERSITY-APP.git
cd ALIYO-MOMOT-UNIVERSITY-APP
```

2. Install dependencies:
```bash
npm install
```

### Running the Application

Start the development server:
```bash
npm run dev
```

The application will open in your browser at `http://localhost:3000`

### Building for Production

Create a production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
